# ⚡ TITAN IT — Enterprise IT Systems & Troubleshooting Reference Hub

**The Biggest, Most Comprehensive IT Engineering Knowledge Base & Rapid Resolution Reference**

Developed as a modern, high-performance HTML/CSS/JavaScript web application designed for Systems Engineers, Helpdesk Administrators, Network Engineers, and IT Specialists.

---

## 🌟 Key Features

1. **Massive Problem-Solution Database**:
   - **Windows Client & Server**: BSoD Crash Analysis (0xEF, 0x0A, 0x7B), BitLocker TPM PCR Lockouts, Startup Repair Loops, 100% Disk Usage / StorAHCI MSI bug, Windows Update Cache flushes, Temporary Profile registry repairs, Print Spooler recovery.
   - **Active Directory & Enterprise M365**: Domain Join Failures (DNS SRV record lookup), Broken Workstation Trust Relationships, GPO Application & Replication failures (`gpupdate /force`), Account Lockout Storms, Entra ID / AAD Connect Sync & Duplicate UPN resolution.
   - **Networking & Connectivity**: APIPA 169.254.x.x DHCP recovery, Duplicate IP Conflicts, DNS Cache Poisoning & Resolution Failures, VPN MTU Fragmentation drops & Split-Tunneling leaks.
   - **Linux & SysAdmin**: Systemd Service Crashloops & unit failure triage, 100% Inode Exhaustion with free disk space, Read-Only Filesystem kernel remounts, SSH `Permission denied (publickey)` StrictModes.
   - **Hardware Diagnostics**: POST Beep Codes Matrix (AMI, Dell, HP) & Motherboard Debug Q-LEDs, NVMe/SSD SMART degradation & bad sector preservation, CPU/GPU Thermal Throttling & AIO pump failure detection.
   - **Cybersecurity & Incident Response**: 60-Second Ransomware Containment Protocol, Phishing Email Header Forensics (SPF, DKIM, DMARC), Volatile Memory Acquisition.
   - **Master Command Vault**: 1-Click Copy PowerShell, CMD, Bash, and Cisco IOS Switchport diagnostic scripts.

2. **Interactive Diagnostic Wizard**:
   - Dynamic symptom decision tree that questions you on observable symptoms (ping results, error codes, boot stages) and isolates the exact root cause and verified fix in seconds.

3. **Field Engineering Toolbox**:
   - **IPv4 Subnet Calculator**: Real-time CIDR (/8 to /30) to Netmask, Wildcard, Network, Broadcast, Usable Range, and Host count.
   - **Batch Repair Generator**: Select desired repair steps (DNS Flush, DHCP Renew, Winsock Reset, ARP Clear, Print Spooler Clean, SFC/DISM Repair) and copy or download an elevated `.bat` script with one click.
   - **Enterprise Port Directory**: Fast searchable TCP/UDP reference for core IT infrastructure ports.

4. **Zero-Lag Instant Search & Filtering**:
   - Filter by Domain, Severity (Critical P1, High P2, Medium P3, Low P4), or Bookmarks.
   - Hotkeys: Press `/` to search from anywhere, `Esc` to close modals, `Ctrl+P` for print-friendly offline cheat sheets.
   - Dark Mode / Light Mode with instant persistence in `localStorage`.

---

## 🚀 How to Run

Simply double-click `index.html` in your web browser (Chrome, Edge, Firefox, Safari).
No installation, npm packages, or web server required—it runs 100% offline out-of-the-box!
